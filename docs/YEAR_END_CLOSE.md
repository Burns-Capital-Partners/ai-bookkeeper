# Year-end close and the next year's opening

The worker does not currently post annual depreciation/amortization automatically. This is an agent/operator procedure using approved schedules. Agree the owner/agent's posting authority and the CPA's review role before execution.

## 1. Close the operating year

- [ ] Review all twelve monthly closes (or the actual fiscal-year months); identify inherited exceptions and missing periods.
- [ ] Verify bank/card/loan/escrow and deposit balances at the year-end cutoff, with intervening activity where a statement ends earlier.
- [ ] Reconcile tenant obligations separately from security-bank custody and operating cash.
- [ ] Review owner transactions, intercompany/clearing accounts, refunds, capital costs, disposals, use changes and all provisional classifications.
- [ ] Tie the year-end trial balance and reports to the underlying ledger; preserve their actual basis and manual-journal visibility.

## 2. Prepare supported annual entries

Obtain acquisition/placed-in-service and improvement/disposal records, prior filed asset schedules, cost-segregation reports where applicable, approved current-year depreciation and loan-cost amortization schedules. Reconcile conflicting sources with the schedule owner/CPA. Do not choose a recovery life from a filename, extrapolate expense from accumulated opening balances, re-depreciate a migrated asset or silently revise a filed return.

For each asset/schedule, retain opening basis and accumulated amounts, additions/disposals, effective business-use allocation, current-year expense and closing balances. Identify whether numbers already represent only the rental share. Personal-use changes, solar credits/catch-up questions and tax elections need the applicable accountant review; a loan payment is not depreciation.

Prepare a journal proposal with stable entity/year/schedule reference, date, accounts/IDs, debit/credit amounts, source schedule revision, basis visibility, allocation already applied, preparer and authority. Search all dates for existing annual/opening/corrective entries before posting. Review the counterpart accounts too. A description saying "opening" may be dated years later.

- [ ] Owner/authorized agent posts the specifically approved annual entries once; the CPA reviews or supplies the schedules according to the agreed responsibilities.
- [ ] Query and inspect the actual published entry and line amounts. A successful form save or API response is not sufficient by itself.
- [ ] Reconcile current-year P&L expense **and** closing accumulated depreciation/amortization to the approved schedules. If adjustments will be made only on the tax return, label that difference and retain the CPA's agreement.
- [ ] Verify year-end and current balances after historical corrections; remove/reverse duplicates only with concrete authority and a complete balance bridge.

## 3. Export, deliver and roll forward

- [ ] Follow [CPA_TAX_HANDOFF](CPA_TAX_HANDOFF.md): labeled reports, support schedules, exception list and one-page context brief.
- [ ] Highlight already-applied personal/rental allocations so the CPA does not reduce the same expenses twice.
- [ ] Deliver only to the authorized CPA/destination; retain the exact version and receipt. Reconcile final CPA adjustments once and re-export.
- [ ] Verify prior closing balances equal next opening balances on the same basis; Zoho normally carries balances forward. Do not add a second opening journal merely because a new year begins.
- [ ] Preserve final report/schedule versions, the migration bridge and remaining exceptions. Lock a period only with the agreed authority and a defined correction path.
- [ ] Verify the recurring runtime and rules still refer to the correct entity/year/use; update dated context where facts changed. Test changes before continuing.

"Monthly books complete," "annual adjustments verified," "CPA package delivered" and "return filed" are separate milestones. State the one actually established.
